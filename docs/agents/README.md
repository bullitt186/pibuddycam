# Agent job guides

Short, task-specific instructions for coding agents. The rules that always apply and the index of
these guides are in [AGENTS.md](../../AGENTS.md). Each guide adds only agent-specific rules and
links the human documentation for everything else.

`pi-ops.example.md` is the template for a maintainer's private live-device runbook, which lives
at the git-ignored `.agent/pi-ops.md`.
